
## 입출력 요구 사항

```
구입금액을 입력해 주세요.
3000
```
- [X] 로또 구입 금액은 1,000원 단위로 입력받는다.

```
3개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
```
- [ ] 발행한 로또 수량 및 번호를 출력한다. (로또 1장의 금액은 1,000이다.)

```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```
- [X] 당첨 번호를 입력받는다. 번호는 쉼표(,) 기준으로 구분한다.

```
보너스 번호를 입력해 주세요.
7
```
- [X] 보너스 번호를 입력받는다.

```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```
- [ ] 당첨 내역을 출력한다.
- [ ] 총 수익률은 소수점 둘째 자리에서 반올림한다.

- [ ] 에러 메시지는 "[ERROR]"로 시작해야 한다.

## 기능 요구 사항
- [X] 로또 번호의 숫자 범위는 1 ~ 45 까지이다.
- [X] 구입 금액에 해당하는 만큼 로또를 발행해야 한다.
- [X] 1개의 로또는 6개의 숫자로 구성되며 중복되지 않는다.
- [X] 사용자가 입력한 구입 금액을 기준으로, 1,000원당 1장의 로또를 생성한다.
- [X] 생성된 로또 번호는 정렬되어야 한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 그 부분부터 입력을 다시 받는다.

## 예외 처리 요구 사항
- [X] 사용자가 입력한 당첨 번호가 6개가 아닌경우 IllegalArgumentException 을 발생시킨다.
- [X] 당첨 번호가 쉼표(,)와 숫자 외의 문자가 포함된 경우 IllegalArgumentException 을 발생시킨다.
- [X] 당첨 번호가 6개가 아닌경우 IllegalArgumentException 을 발생시킨다.
- [X] 당첨 번호와 보너스 번호가 1 ~ 45의 숫자가 아닌경우 IllegalArgumentException 을 발생시킨다.
- [ ] 보너스 번호가 당첨 번호에 포함된 숫자라면 IllegalArgumentException 을 발생시킨다.

```
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개

5개 일치, 보너스 볼 일치 (30,000,000원) - 0개

```
